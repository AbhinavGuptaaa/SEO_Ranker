<h1>AI SEO Rank Tracker & Website Analyzer</h1>

An AI-powered full-stack SaaS platform built using the MERN stack. This tool automates the process of auditing website SEO metrics, tracking search engine keyword rankings against competitors, and generating detailed optimizing strategies using Google Gemini AI.

<h1>Key Features</h1>

  * Dark & Light Mode Toggle: Seamless appearance switcher built across the entire user experience.

  * Full JWT Authentication: Secure Sign Up, Sign In, and Log Out workflows incorporating bcrypt password encryption.

  * Automated SEO Audit: Deep scans web architecture to extract performance metrics (page size, loading speed, heading hierarchies, images without alt tags, and total link distribution).

  * Google Gemini AI Reports: Leverages GenAI to process audited page elements and dynamically generate custom, smart SEO optimization strategies.

  * Live Keyword Ranking Tracker: Utilizes cloud-automated headless browser routines to scrape Google SERPs (up to 5 pages deep) and trace live ranking positions.

  * Competitor Analysis: Tracks keyword positions alongside top competing URLs in an elegant drop-down comparison chart.

  * Automated Daily Refresh (Cron Jobs): Features an automated server cron scheduler running daily at 6:00 AM to automatically fetch updated search rankings.

  * Historic Metrics Log: Displays a timeline of previous scans, average SEO score tallies, daily quota allowances, and historical ranking position adjustments.
